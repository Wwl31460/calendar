安装步骤

  1. 点上面的按钮下载（别在微信里下，用手机自带浏览器 / Chrome / 夸克）
  2. 下载完成后点通知里的文件，或在「文件管理 → 下载」里点开
  3. 提示「安装未知应用」时，允许浏览器安装应用
  4. 覆盖安装即可，原来的日程 / 日志 / 课表都还在

装好后打开 App →「设置 → 检查更新」应显示 v1.3.2。

图标还是旧日期？

打开 App 后如果桌面图标仍是升级前那张，按顺序做一次：
① 进「设置」→ 点「桌面图标」那一行（会显示今天应是几月几日星期几）
② 长按桌面图标 → 移除 → 从应用列表拖回桌面
③ 还不变就重启一次手机，桌面会重新读取图标。
